# Roadmap

Possible next steps. All optional; this is a personal project.

- **Follow-up questions** — ask a follow-up about the current lookup (e.g.
  another example or a different tense) without retyping the word.
- **Translation quality** — better handling of less-resourced languages
  and more natural phrasing for longer texts.
- **Localized interface** — translate the remaining fixed UI labels into
  the user's chosen language.
- **Deployment** — proper hosting with per-user access and rate limiting.
